# Interactive Buddy Desktop Rust

A clean project repository for the Rust/Bevy Interactive Buddy desktop application.

The rewritten Rust/Bevy source and Cargo manifests are included under `rewrite/`. The extracted SWF/decompilation, supplied art/audio, generated packages, and binaries are intentionally excluded from this repository by `.gitignore`. The Windows build is distributed separately through the GitHub Releases page.

Download the latest Windows x64 release, extract it, and run `Start Buddy.vbs`. The release package includes the desktop overlay, Lock to window mode, lower-right menus, window interactions, visible Exit controls, and Ctrl+Alt+Q.

This repository does not redistribute the original Flash source or extracted media. See the release notes for build provenance and limitations.
