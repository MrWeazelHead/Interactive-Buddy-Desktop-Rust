# Parity with Interactive Buddy

The native version uses the supplied local v1.02 SWF extraction as its data and media source. The original historical submission is [Interactive Buddy v.1.01 on Newgrounds](https://www.newgrounds.com/portal/view/218014). The different version numbers matter: the extracted v1.02 catalog is authoritative for this port, but does not prove every detail was identical in v1.01.

| Area | Current parity | Notes |
| --- | --- | --- |
| Catalog | Exact to supplied v1.02 source | Item, skin, and mode labels, prices, internal IDs, and starting ownership come from the extracted ActionScript definitions. |
| Art and audio | Extracted originals | Buddy skins, tool sprites, room art, and WAVs are prepared from the supplied SWF. Sprite registration is normalized for the renderer. |
| Interface | Approximate native redesign | Windows launches into a transparent always-on-top desktop overlay by default; `--classic` selects the contained game window. The lower-right menu strip follows the supplied sketch (File, Skins, Items, Modes, Settings, Help), with an options panel above/left of Buddy and a collapsed strip mode. This interaction model and appearance are new native UI, not a reproduction of Flash menus. |
| Physics | Source formulas ported, incomplete surrounding state | Six body parts use the source spring strengths, weighted torso response, damping paths, rotated anchors, rigid reach, boundaries, and bounce. Awake and clock skin branches are present. The full collision scheduling and action-state interactions still differ. |
| Tools | All 28 catalog entries selectable | Explosions use the source distance/falloff/reward formula. Guns use moving bullets, sixteen collision samples, original speed/spread/strength, eight shotgun pellets, and five-frame machine-gun cadence. Throwables use source masses and circle collision response. Fire, water, flail, deletion, and some special interactions remain approximate. |
| Modes | Partial approximation | Common modes affect gravity, physics, camera, effects, and presentation. Individual source details may differ. |
| Buddy response | Partial source behavior | Tickle and hand-follow rewards, happy idle rewards, flips, grenade avoidance, radio-targeted dancing, health/knockout, and burn reactions are present. The complete priority queue, timers, comments, and voice triggers are not ported. The original mood-face frames are rendered. |
| ShockScript | Subset | Includes source operator semantics, variables, lazy conditions, bounded loops, math helpers, buffers, dynamic evaluation, Buddy velocity/position/rotation/emotion, bullets, sound, and catalog unlock. Named object access, constraints, and several original APIs remain unsupported and report an error. |
| Desktop window effects | Native approximation, Windows only | In armed desktop play, impacts can snapshot a top-level window, show the snapshot as temporary debris, and minimize that window. Restore Windows and application exit restore affected windows to captured rectangles. This is reversible; windows are not closed or terminated. Capture may fail for protected or non-capturable windows, and other platforms do not perform native window effects. |
| Saving | Simplified | Progress is stored as JSON in the working directory. This does not use the original Flash SharedObject format. |

Directional gun aim is implemented with **Shift**; combining it with **Ctrl** targets the head. Throwable objects launch using the full drag from the starting point; Open Hand retains the release velocity of the grabbed body part. The supported source cheat sequences include cash, unlock-all, and emotion changes; they do not imply that every original cheat is supported.

On Windows, the default launcher starts the Buddy overlay above other windows. Its narrow lower-right strip opens File, Skins, Items, Modes, Settings, and Help; the option panel is positioned above and left of Buddy so the character remains visible along the taskbar edge. Selecting the current strip entry again hides the option panel. The **Play anywhere** switch controls input capture: ordinary desktop mode responds to Buddy and the overlay controls, while armed mode lets tools target anywhere on the desktop; **Esc** disarms it. Explosions and supported impacts can affect visible windows. Window snapshots exist only in memory, windows are minimized rather than closed, and **Restore Windows** or application exit restores windows the game minimized. This operating-system integration is a new native feature, not original Shockwave behavior, and its capture behavior is subject to Windows and application restrictions.

The native application is still an incomplete port rather than a 1:1 recreation. Source assets and many formulas are reused, but visual layout, portions of the physics/action state machine, tool interactions, modes, audio triggers, and several ShockScript APIs remain approximate or unsupported. A passing native smoke test is not evidence of full parity; the outstanding details are listed above and should be compared with the extracted scripts before being described as exact.

The original mood-face animation is available as 20 extracted frames in `assets/mood/`, and is rendered at the source position and scale, driven by the Buddy's emotion.

Low Gravity uses the source 35% factor; an active Gravity Shifter removes normal gravity. Vortex forces use the source formulas. NES Style Movement uses the source twelve-pixel quantization. Earthquake adds randomized impulses to grounded bodies and objects. The FPS counter measures native render rate; the simulation remains 36 Hz. Dynamic Camera and visual effect modes remain approximations.

For exact item data and extracted source details, see [`assets/catalog.json`](assets/catalog.json), [`assets/asset_manifest.json`](assets/asset_manifest.json), [`assets/tools/tool_manifest.json`](assets/tools/tool_manifest.json), and the repository's [`REFERENCE.md`](../REFERENCE.md).
